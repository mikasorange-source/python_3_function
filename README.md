# Expense Health Checker

月ごとの支出をカテゴリごとに記録し、  
予算に対する消費率や家計の健全度をチェックできる **Pythonの簡易家計簿アプリ**です。

## 概要

このプログラムでは以下のことができます。

- カテゴリごとの支出入力
- カテゴリの追加
- 予算に対する消費率の計算
- 各カテゴリの家計状態判定
- 全体の家計状態判定
- 支出が最も多いカテゴリの表示
- 危険カテゴリのアドバイス表示

---

## 使用技術

- Python
- 辞書（dictionary）
- 関数
- whileループ
- 入力バリデーション

---

## 使い方

プログラムを実行すると、次のように支出カテゴリを選択できます。

```text
記録したい支出のカテゴリはなんですか？
0:追加/1:食費/2:日用品/3:娯楽/4:交通費/5:その他
```

### カテゴリ追加

`0:追加`

を入力すると新しいカテゴリを追加できます。

```text
追加したいカテゴリの名前を入力してください：
追加したいカテゴリの1ヶ月の予算を入力してください：
```

---

### 支出入力

カテゴリを選択すると支出を入力できます。

```text
いくら使いましたか？
```

---

### 続けて入力

```text
今月の入力を続けますか？0:yes/1:no
```

---

## 出力例

```text
食費：支出12000円・予算30000円・残金18000円・消費率40％・判定健全
日用品：支出3000円・予算10000円・残金7000円・消費率30％・判定健全
娯楽：支出10000円・予算15000円・残金5000円・消費率66％・判定注意
交通費：支出8000円・予算10000円・残金2000円・消費率80％・判定注意
その他：支出0円・予算20000円・残金20000円・消費率0％・判定健全
```

### 全体判定

```text
総支出33000円・総予算85000円・全体判定健全
```

### 最大支出カテゴリ

```text
一番支出の多いカテゴリは娯楽です（10000円）
```

### アドバイス

```text
来月は娯楽、交通費カテゴリの支出を抑えましょう
```

または

```text
危険カテゴリなし
```

---

## 判定基準

### カテゴリ判定

| 条件 | 判定 |
|------|------|
| 支出 > 予算 | 危険 |
| 消費率70%以上 | 注意 |
| それ以外 | 健全 |

※交通費は80%以上で注意

### 全体判定

| 消費率 | 判定 |
|--------|------|
| 70%以下 | 健全 |
| 70%〜100% | 注意 |
| 100%以上 | 危険 |

# Quiz Game

Pythonの基礎知識を学習できる **3択クイズゲーム**です。  
選択肢は毎回ランダムに並び替えられ、**番号入力・文字入力の両方**で回答できます。

## 概要

このプログラムでは以下のことができます。

- Pythonに関する3択クイズの出題
- 選択肢のランダム表示
- 番号または文字で回答
- 入力チェック
- 正誤判定
- 正解の表示
- 正答率の計算

---

## 使用技術

- Python
- 関数
- リスト
- 二次元リスト
- モジュール分割
- whileループ
- 入力バリデーション
- `random.shuffle()`

---

## 使い方

プログラムを実行するとクイズが始まります。

```text
クイズゲームへようこそ！
```

各問題で選択肢が表示されます。

```text
問題1
Pythonで文字を表示するときに使うものはどれ？

1:show
2:print
3:output
```

回答は

```text
2
```

のように番号で入力しても、

```text
print
```

のように文字で入力しても構いません。

---

## 出力例

```text
問題1正解！

問題2不正解...正解はinputでした！

問題3正解！

3問中2問正解でした！
正答率67%
```
